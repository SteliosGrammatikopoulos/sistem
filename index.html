ProΣτεγη CRM

Επαγγελματικό CRM για ενεργειακές εγκαταστάσεις. Πελάτες, προσφορές, αυτοψίες, εγκαταστάσεις, οικονομικά και ιστότοπος — όλα σε μια ενιαία πλατφόρμα.

Εγκατάσταση

Ξεκίνα σε 4 βήματα

Απαιτείται Bun (ή npm/yarn) και Node.js 20+. Η βάση είναι SQLite — δεν χρειάζεται εξωτερικός server.

1

Κλώνοποιήσε το repository

Με git clone κατέβασε τον κώδικα και μπες στον φάκελο του project.

bash
# Clone & enter
git clone https://github.com/<your-org>/prostegi-crm.git
cd prostegi-crm
2

Εγκατάστησε τις εξαρτήσεις

Χρησιμοποιούμε Bun για ταχύτητα. Εναλλακτικά npm install ή yarn.

bash
bun install
3

Ρύθμισε το .env & τη βάση

Δημιούργησε αρχείο .env με το DATABASE_URL και το NEXTAUTH_SECRET. Μετά τρέξε τις εντολές Prisma.

.env
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET="change-me-please"
NEXTAUTH_URL="http://localhost:3000"
bash
# Generate client & create the database
bun run db:generate
bun run db:push
4

Ξεκίνα τον dev server

Άνοιξε http://localhost:3000 στον browser. To splash screen θα εμφανιστεί για ~1.2s και μετά το login.

bash
bun run dev

# Production build & start
bun run build
bun run start
